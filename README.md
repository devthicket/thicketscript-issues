# ThicketScript issues

Bug reports and feature requests for [ThicketScript](https://www.thicketscript.com/): the language, the ThicketScript
runtime (`thicket`), its modules and the IDE plugins.

| Label | Area |
|---|---|
| `language` | Syntax, the type checker, error messages |
| `runtime` | The `thicket` runtime: running, the VM, performance, crashes |
| `willow` | willow, the 2D module |
| `willowui` | willowui, the UI toolkit |
| `gamekit` | gamekit, the game-structure package |
| `ide-plugin` | The JetBrains and VS Code plugins, the language server, debugging |
| `build` | Building and packaging games |
| `docs` | The docs and thicketscript.com |

This repository holds issues only; the ThicketScript source is not here.

## Before you open an issue

- **Search first.** Someone may have reported it already; add a 👍 or your details to that issue instead.
- **One problem per issue.**
- **Questions and help** are quicker in the [Discord](https://discord.gg/phanxgames).
- **The editors** (Waystone: RPG Creation Studio and the others) have their own issues:
  [thicketcreator-issues](https://github.com/devthicket/thicketcreator-issues).

## Opening an issue

Choose **New issue** and pick a template: **Bug report**, **Feature request** or **Docs problem**. Tell us your
`thicket --version`, your operating system, and the smallest `.tks` script that shows the problem. A short script we
can run is the fastest way to a fix.
